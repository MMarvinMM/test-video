# 系统开发文档

## 系统功能简介

### 1. 系统管理

#### 1.1. 用户管理

- 用户查询：支持按照所在部门、登陆账号、手机号码、状态、创建时间区间进行筛选查询用户
- 用户新增：新增用户包含昵称、账号、密码、部门、手机号码、邮箱、性别、状态、岗位、角色和备注字段
- 用户信息修改：支持用户信息修改
- 用户批量导入：支持批量导入用户信息
- 用户信息导出：支持用户信息导出
- 用户批量删除：支持多选用户批量删除
- 用户状态启用和禁用：支持管理员启用于禁用用户，被禁用的用户无法登录系统
- 用户密码重置：支持管理员重置用户密码，可重置为系统参数中配置的默认密码

#### 1.2. 角色管理

- 角色查询：支持按照角色名称、权限字符、状态、创建时间区间进行筛选查询角色信息
- 角色新增：新增角色信息包括角色名称、权限字符、角色顺序、角色状态、菜单权限和备注字段
- 角色信息修改：支持角色信息的修改
- 角色批量删除：支持多选角色批量删除
- 角色信息导出：支持角色信息导出
- 角色菜单权限配置：支持配置拥有该角色用户所能访问的菜单权限
- 角色数据权限配置：
  - 全部数据权限：即不过滤任何数据
  - 自定义数据权限：可进行自定义部门数据权限
  - 本部门数据权限：只能查询该部门所属数据
  - 本部门及以下数据权限：可查询本部门及下属部门的所有数据
  - 仅本人数据权限：只可查询本人创建的数据
- 角色的启用和禁用：支持角色的启用和禁用，已禁用的角色将无法使用

#### 1.3. 菜单管理

- 菜单查询：支持按菜单名称和状态进行筛选查询，并进行树形展示
- 菜单新增：新增菜单信息包含上级菜单、菜单类型、菜单图标、菜单名称、显示排序、是否外链、路由地址和菜单状态字段
- 菜单编辑：支持菜单信息的编辑修改
- 菜单删除：支持菜单信息的删除
- 按钮管理：支持菜单下按钮级别的管理

#### 1.4. 部门管理

- 部门查询：支持按部门名称和状态进行筛选查询并进行树形展示
- 部门新增：新增部门信息包含上级部门、部门名称、显示排序、负责人、联系电话、邮箱和部门状态字段
- 部门编辑：支持部门信息的编辑修改
- 部门删除：支持部门信息的删除

#### 1.5. 岗位管理

- 岗位查询：支持按岗位编码、岗位名称和岗位状态进行筛选查询
- 岗位新增：新增岗位信息包含岗位编码、岗位名称、岗位状态、显示排序和备注字段
- 岗位编辑：支持岗位信息的编辑修改
- 岗位删除：支持岗位信息的删除
- 岗位信息导出：支持岗位信息的导出

#### 1.6. 字典管理

- 字典查询：支持按字典名称、字典类型、状态、创建时间区间进行筛选查询
- 字典新增：新增字典信息包含字典名称、字典类型、状态、备注和字典数据
- 字典修改：支持字典信息的修改编辑
- 字典删除：支持字典信息的删除
- 字典导出：支持字典类型信息的导出
- 字典数据管理：
  - 字典数据查询：支持按字典类型名称、字典标签、字典数据状态进行筛选查询
  - 字典数据新增：新增字典数据包括所属字典类型、数据标签、数据键值、显示排序、状态和备注字段
  - 字典数据修改：支持字典数据的修改编辑
  - 字典数据删除：支持字典数据的删除
  - 字典数据导出：支持字典数据的导出

#### 1.7. 系统参数

- 系统参数查询：支持按参数名称、参数键名、是否系统内置、创建时间区间进行筛选查询
- 系统参数新增：新增系统参数包含参数名称、参数键名、参数键值、是否系统内置和备注字段
- 系统参数修改：支持系统参数信息的修改
- 系统参数删除：支持系统参数信息的删除
- 系统参数导出：支持系统参数信息的导出

#### 1.8. 通知公告

- 通知公告查询：支持按公告标题、操作人员和类型进行筛选查询
- 通知公告新增：新增通知公告包含公告标题、公告类型、公告状态、公告内容字段
- 通知公告修改：支持通知公告信息的修改编辑
- 通知公告删除：支持通知公告信息的删除

#### 1.9. 日志管理

##### 1.9.1. 操作日志

- 操作日志查询：支持按系统模块、操作人员、类型、状态、操作时间区间进行筛选查询
- 操作日志详细：支持查看每条日志的详细内容包含操作模块、请求地址、登录信息、请求方式、操作方法、请求参数、返回参数、操作状态和操作时间字段内容
- 操作日志导出：支持操作日志信息的导出
- 操作日志批量删除：支持操作日志信息的批量删除与清空

##### 1.9.2. 登录日志

- 登录日志查询：支持按登陆地址、用户名称、状态和登陆时间区间进行筛选查询
- 登录日志导出：支持登录日志的导出
- 登录日志批量删除：支持登录日志的批量删除和清空

### 2. 系统监控

#### 2.1. 在线用户

- 在线用户查询：支持按登陆地址和用户名称进行筛选查询
- 在线用户强制下线：支持管理员对在线用户的强制下线操作

#### 2.2. 任务调度

- 运行报表：支持调度任务运行的报表展示
- 任务管理：支持调度任务的新增和操作
- 调度日志：支持调度任务日志的查询和详情展示
- 执行器管理：支持任务执行器的新增编辑和删除

#### 2.3. 数据监控

监控数据源信息和执行情况

#### 2.4. 服务监控

- 监控服务所在主机的硬件资源如：CPU、内存等信息
- 监控Java虚拟机的运行信息
- 监控服务所在主机的磁盘信息


## 本地WEB环境搭建
### WEB后端搭建启动
1. 安装`redis`，默认本地开发环境为`127.0.0.1:6379（无密码）`
2. 启动CompAdminApplication

### WEB前端搭建启动
1. 安装 `node`
2. 打开命令窗将目录 `cd` 到 `ebike-server-ui`目录下执行 `npm i`，确认安装过程没有报错
3. 执行 `npm run dev` 启动前端项目
4. 点击启动成功后打印出的连接地址进行访问 账号：`admin` 密码：`tttt123.`

## 代码开发规范
### 前端规范
1. 使用代码生成时将生成的api下的文件夹和view下的文件夹分别对应拷贝到`api/modules`下和`views/modules`下
2. 实体类必须集成父类 `com.chinatower.platform.framework.web.domain.BaseEntity`
### 后端规范
1. 使用代码生成时将生成的Java下的模块文件夹和resources下的xml文件夹分别对应拷贝到`com.chinatower.platform.project.modules`下和`mybatis.modules`下
### 数据库表设计规范
1. 业务数据表表名统一用`bs_`开头，其他表可用`tb_`开头
2. 在使用代码生成功能时会将第一个下划线到第二个下划线中间的字符作为模块名
3. 在使用代码生成功能时会将弟一个下划线后的所有字符作为对象名
4. 每个业务表必须有以下字段，方便后期维护和进行数据过滤
    - `DEL_FLAG`      删除标志（0未删除 2已删除）   字符串类型（1） 默认0
    - `CREATE_BY`     创建者账号                 字符串类型（50）
    - `CREATE_TIME`   创建时间                   时间类型
    - `UPDATE_BY`     更新者账号                 字符串类型（50）
    - `UPDATE_TIME`   更新时间                   时间类型
    - `DEPT_ID`       所属部门                   字符串类型（20）
